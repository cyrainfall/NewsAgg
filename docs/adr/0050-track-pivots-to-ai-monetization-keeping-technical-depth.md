# 赛道从「AI 与开发者工具」转向「AI 变现与开发者职业」，保留技术底子

**Status**: 已接受并落地（2026-10-21）。取代 Q6 的赛道定案，并取代
[ADR-0049](0049-feed-crops-to-3x2-so-layout-inside-safe-zone.md) 的 Decision 6
（「本 ADR 不改赛道」）。

## Context

Q6 定案赛道为「AI 与开发者工具 / 技术行业」，并明确「暂不细分」。ADR-0049 在诊断阅读量时发现了与这条定案直接冲突的证据，且该证据不是猜测，是三条独立的实测：

1. **曝光在涨，点击不涨。** 6 篇合计展现 1782、阅读 2、整体点击率 **0.11%**；渠道分布 **推荐频道 92.63%** / 主页 5.90% / 搜索 0.08%。最新一篇 0.1 天就拿到 51 次展现，折合 464 次/天，且仍在爬升。**平台确实在推，是推了没人点。**
2. **平台内没有这个赛道的读者。** 头条站内搜索 `Codex` 与 `MCP` 均返回**零相关结果**（分别是「Codex Design」、食品法典、磁罗经导航）。而 `AI 赚钱` / `AI 副业` 有大量存量内容，`程序员 失业` 单条最高 22 评论、`大模型 降价` 最高 21 评论。
3. **主榜不供给这个赛道。** 头条主榜跨 10-17 至 10-20 进池 18 条，属于「AI 与开发者工具」赛道的 **0 条**；主榜是娱乐社会驱动（「岳云鹏相声听不清」「AI 救前夫」）。

ADR-0049 当时的处置是：**不在实现层偷偷改赛道**，因为那是产品决策。本 ADR 记录该产品决策已被做出——本人于 2026-10-21 选择「改：往『AI 赚钱/副业』偏，保留技术底子」。

## Decision

**一、赛道改为「AI 变现与开发者职业」，技术深度保留为差异化手段而非选题主题。**

准确表述：**选题的落点是「钱」与「职业处境」，论证的材料仍然是技术与工程细节。** 不是放弃技术，而是把技术从「主题」降为「证据」。

这与既有观点卡体系相容，因为多数卡本来就谈钱与处境：
`personal-ai-monetization-is-paid-demand-not-technology.md`（个人变现）、`ai-capital-pricing-shifts-to-unit-economics.md`（资本定价）、`llm-price-war-signals-commoditization.md`（价格战）、`ai-replacing-developers-misreads-the-work.md`（开发者替代）、`ai-coding-workflow-over-model-capability.md`（工具选择）。**不需要新建卡体系**，只需要改变排序偏好与写作落点。

**二、采集层只补「个人变现与职业处境」的词，不补泛化的钱词。**

实测（5 天 dropped 池共 1306 条）证明补词必须精准，否则全是噪音：

| 词 | dropped 命中 | 判定 |
|---|---|---|
| `副业` | 1（「探索副业五个月，最终以放弃告终」） | **收录**，正是新方向 |
| `赚钱` | 4（手术机器人同行赚钱 / 卖 Token 不好赚钱） | **收录**，2/4 相关 |
| `变现` `知识付费` `独立开发` `自由职业` `接单` `月入` `客单价` `付费` `订阅` `私域` `涨粉` `流量主` `广告分成` `带货` `商单` `SaaS` `小程序` `出海` | 多为 0 | **收录**，词表是给未来供给用的 |
| `失业` `薪资` `工资` | 各 0~1 | **收录**（职业处境） |
| `收入` | 3（银行净息差 / C罗收入 / 人均可支配收入） | **不收录**，全是噪音 |
| `涨价` `降价` `免费` `成本` `盈利` | 4/1/18/1/1，全是硬件促销与财报 | **不收录**，全是噪音 |
| `IP` | 73，全部命中 iPhone | **不收录**，灾难性误筛 |
| `钱` | 过宽 | **不收录** |

**关键判据**：词表要收的是「个人/小团队如何挣到钱」与「职业处境如何变化」的**语汇**，不是「金额」的语汇。后者在热榜里全部来自消费电子折扣与上市公司财报。

**三、分拣层增加一条排序偏好（不新增硬规则）。**

当两个聚簇的「匹配度 × 热度」**相当**时，优先选**有明确钱落点或职业处境落点**的那一个。与 ADR-0010 的历史表现软信号同级：**参与排序，不参与打分，不设阈值**。

理由：把它写成硬规则（例如「无钱落点即弃权」）会让系统在只有技术新闻的日子系统性弃权，而弃权是合法结果但不是目标。写成偏好则保留了判断空间。

**四、写作阶段增加一条内容要求：钱落点必须能被读者对号入座。**

brief 的「内容要求」新增一条——文章必须回答「这件事跟读者的钱或工作有什么关系」，且必须是**具体到角色**的回答（「接外包的前端」「做小程序的独立开发者」），不是「对行业有影响」。与既有的「至少给一个具体场景」互补：后者要求场景，这条要求场景里有**人的处境**。

**五、不改变的部分（明确列出，避免后续误读为「全盘推翻」）。**

- 观点卡体系、三态决策、冷却期、每日 1 篇、无人值守、发布链路全部不变。
- `platforms/niche.txt` 仍是**本人所有**（ADR-0018），本次改动由本人授权。
- 封面、照片、排版三条（ADR-0044/0048/0049）不变——它们只影响「看到之后点不点」。
- 技术深度仍是差异化的来源。放弃技术会掉进「AI 赚钱」内容的同质化红海（该关键词下已有大量存量），本 ADR 选择的是**用技术细节支撑钱的判断**，而不是改写成情绪文。

## Consequences

- **短期阅读量仍可能很低。** 改赛道改变的是「选题落在哪」，不改变「账号是第 7 天、0 粉丝、无原创标记」。头条的冷启动分发对无粉丝新号的初始流量本来就小，本 ADR 不承诺阅读量会立刻上升。
- **新增一类失败模式：写成「AI 赚钱」同质文。** 该关键词下存量内容极多，若写作阶段只抓「钱」不抓「技术证据」，产出会与存量无差别。缓解是 Decision 四的「具体到角色」要求，但它是写作纪律而非可执行检查——**没有自动校验**。
- **既有观点卡里有几张将长期用不上。** `open-source-llm-bottleneck-is-ops-not-capability.md`、`ai-productivity-claims-lack-reproducible-benchmarks.md` 偏纯技术议题，在新方向下匹配机会显著减少。它们不退役（ADR-0010：软信号不触发退役），但会长时间处于未匹配状态。
- **赛道定义同时出现在四处**（`platforms/niche.txt` 头注释、`.wewrite/style.yaml` 的 `industry`/`topics`/`target_audience`、`GLOSSARY.md` 的「赛道」词条、`DESIGN.md` 的核心取舍表）。本次同步更新全部四处；**这本身是个脆弱点**——赛道是单一概念却有四个副本，与 ADR-0042 修过的「三份 frontmatter 解析器漂移」同型。本次不抽单一实现（它们是给人读的自然语言，不是可执行的解析逻辑），但记录该风险。
- **`style.yaml` 是本人所有的资产**（该文件头注释明写「内容归本人所有，系统不直写」），本次改动由本人明确授权方向后执行，diff 需本人复核。
