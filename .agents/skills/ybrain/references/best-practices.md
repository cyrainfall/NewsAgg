# 最佳实践：ybrain 上手与价值指南

写给第一次使用 ybrain 的用户；agent 在 Bootstrap、首次各工作流、以及用户问"这技能怎么用/有什么用"时阅读本文件并据此引导。

## 这个技能解决什么问题

三个老痛点：

1. **收藏了，找不到**——信息散落在各处，用的时候想不起来在哪
2. **看过了，记不住**——大脑是用来创造想法的，不是用来存储的
3. **想写了，从白纸开始**——平时的积累没有变成创作时的素材

ybrain 用 CODE 循环（捕获→组织→提炼→表达）+ PARA 组织法，让信息在你的 IMA 里沉淀成**你自己的知识网络**。核心主张就一句：**输出即学习**——所有输入都是为了在合适的时候做一次漂亮的表达。

## 第一次使用：五步体验闭环

按这个顺序体验一遍，你就完整看到了 CODE 循环：

0. **备好凭证**（一次性前置）：到 https://ima.qq.com/agent-interface 领取 clientId / apiKey，设为 `IMA_OPENAPI_CLIENTID` / `IMA_OPENAPI_APIKEY` 环境变量，或写入 `~/.config/ima/client_id` 与 `~/.config/ima/api_key`。没有凭证，技能连不上你的 IMA。
1. **破冰**：直接说一句「记一下 https://任意一篇好文章」。技能检测到 ybrain 结构不存在时，会给你一张创建清单（知识库 ybrain + 五个 PARA 文件夹 + 笔记本 ybrain + 收件箱笔记），**一次确认全部自动建好**，无需手动准备任何东西。
2. **第一笔捕获**：再「记一下」一两条。注意它**不问你分类**——这是刻意的：捕获要快，不打断心流。
3. **第一次整理**：攒了几条后说「整理收件箱」。看技能逐条做四问筛选（这对哪个项目有用？→ 哪个领域？→ 哪个资源？→ 存档或不存），给出建议表；你确认后，它自动把每条归位。
4. **第一次提炼**：挑一条最有感觉的，说「提炼这篇」。看它从原始材料变成知识包里的一篇活笔记——这篇笔记以后会持续追加、越用越值钱。
5. **第一次表达**：说「帮我起草一篇关于 X 的短文」。素材清单 → 你确认 → 草稿 → 费曼式自检 → 成品存为【输出】笔记。**这一刻闭环完成**：几天前随手捕获的信息，变成了你的作品。

## 日常节奏（推荐）

| 动作       | 频率                               | 耗时                     |
| ---------- | ---------------------------------- | ------------------------ |
| 捕获       | 随时，想到就记（移动端直接存 IMA） | 3 秒/条                  |
| 整理收件箱 | 每周一次，比如周末                 | 10 分钟                  |
| 提炼       | 整理时顺手做，或读到好东西当场说   | 5 分钟/篇                |
| 表达       | 每月至少一篇                       | 由外脑供料，远比从零写快 |

## 价值从哪来（为什么值得坚持）

- **第 1 周**：省的是"找"的时间——任何存过的东西，问一句就有
- **第 1 个月**：知识包开始体现复利——同一主题的思考不断叠加，而不是散落几十篇碎片
- **第 3 个月**：表达不再从白纸开始；你的输出（【输出】笔记）开始回流为下一次创作的素材。**知识内化的标志，就是你的输出开始喂养你的输入**

## 好习惯

- 只捕获**有共鸣**的——收件箱不是垃圾桶，什么都存等于什么都没存
- 捕获不问分类，整理才分类——保护心流，也避免"分类太麻烦最后干脆不记"
- 知识包**一题一篇、持续追加**——蒸馏增值，每一次记录都增加这篇笔记的价值
- 输出必须留痕——成品存【输出】笔记，它是未来自己的知识包

## 反面模式（收藏夹墓地是这样形成的）

- **只进不出**：从不表达，外脑退化成坟场
- **当场分类**：捕获成本变高，三次之后你就再也不记了
- **完美主义分类**：PARA 四个问题就够了，不要建图书馆——最好的分类就是无需分类，剩下的交给搜索
- **收件箱只进不理**：定期整理是这个系统的节拍器，断了节拍，系统就死了

## 给 agent 的引导要点

- Bootstrap 完成时，用一句话告诉用户建了什么、为什么是这个结构（双层：知识库存原始材料，笔记存你的想法）
- 每个工作流**首次**完成时，说清"刚才发生了什么、东西存在哪了"，并建议下一个值得体验的工作流（按上方五步顺序）
- 用户问"你能做什么/这有什么用"时，用「这个技能解决什么问题」+「五步体验闭环」回答，不要罗列 API
- 检测到缺少 IMA 凭证时，不要重试也不要换路径：明确告知到 https://ima.qq.com/agent-interface 获取 clientId / apiKey，并按「第 0 步」的两种方式之一配置，配好后重跑当次操作
