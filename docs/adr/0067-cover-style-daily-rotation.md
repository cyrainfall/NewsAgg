# 封面样式每天换一种：有限目录 + 日期哈希

## Context

封面自 2026-10-20 重构以来（ADR-0044）一直是同一种长相：深夜蓝黑底、蓝强调线、
Heiti 显示字体。视觉上没有问题，但连续看了十几天后暴露出另一件事——
**信息流里的封面不会因为「内容好」而被点开第二次，却会因为「又是同一张脸」被划过去**。
样式单一在无人值守系统里不是审美问题，是 CTR 问题：用户每天看到的是同一个模板，
学习效应让它退化成壁纸。

学习了 reference/hallmark（Together AI 的 48 主题设计 skill）后拿到一个关键区分：
**主题是材质（纸、墨、强调色、显示字体），不是排版计划**。排版与材质正交，
同一论据在任何材质下都该走同一套测量、同一组自检。这正是 NewsAgg 封面需要的：
我们要的是「每天换一张脸」，不是「每天换一套会出新错的排版」。

候选方案：

1. **每天真随机**（`random.choice`）——重跑一次封面就换长相，不可复现；无人值守
   系统一天可能生成封面多次（重跑、补发），「今天的封面是哪一种」会变成薛定谔的。
2. **状态文件记录昨天用的样式**——状态文件会坏、会丢、会被 git 搞脏；
   ADR-0038 的看守模式专门绕开了这类文件。
3. **有限目录 + 日期哈希**（选定）——确定性、无状态、跨天自然轮换。

## Decision

**`make_cover.py` 新增有限样式目录（8 种）与按日期哈希的确定性选择。**

- 样式是材质声明：`bg` / `ink` / `muted` / `accent` / `alt` 五色 + 显示字体
  （路径 + ttc index）+ 明暗标志 + 装饰条位置。8 种：`ink`（原版）/ `paper`（报纸
  白纸宋体）/ `slate` / `cream` / `cobalt` / `forest` / `mono` / `blush`。
  所有字体实测过有真实 CJK 字形（逐字 textbbox 验证，排除过零宽豆腐块的
  Yuanti 子集）。
- 选择规则：`zlib.crc32(日期)` 对目录长度取模；与昨天撞上同一种时 +1 错开。
  同一天重跑必一致——幂等不需要状态文件。
- 覆盖通道：`--style` / spec `"style"` 显式钉死；**未知名字硬错退出 1**，
  绝不静默回退（同 ADR-0044 对 --spec 的纪律：静默回退会让「我明明指定了」
  变成无人验证的假设）。
- 信息 dict 新增 `style` / `style_pinned`，供简报层呈现「今日封面样式」。

**样式不允许引入任何新的自检豁免。** 三个布局函数只多收一个 `style` 参数；
字号测量（`fit_font` / `fit_block`）改为用**将要画出去的那支字体**测量
（`font_fn`），因为不同字体的同字号宽度不同，拿 A 字体测量、用 B 字体绘制，
自适应就是拿错觉当依据。3:2 安全区、可读性下限、复述标题检测全部原样生效。

## 为什么像素自检必须跟着样式走

`edge_check` / `safe_zone_check` 原先把「是墨不是底」写死为与 `INK` 的
sum-abs 距离 > 60。引入浅纸底（`paper` / `cream` / `blush`）后这个判据
全体失效——白纸底上的判断基准不存在。修法：底色由样式声明，检查按与
**该样式底色**的距离识别墨。每种样式的墨色与底色 sum-abs 必须 > 60，
这一点由测试钉住（`tests/test_make_cover_style.py`），否则换一种样式
就能让自检从把关退化成全体通过——那正是 ADR-0044 发现六的复刻。

## 为什么不（更丰富的方案）

- **更多样式（16/48 种）**：目录越长，单个样式的出勤率越低，每种样式在真实
  信息流里被验证的机会越少——不如 8 种各站一个明确的观感位。
- **按内容选样式**（数字封面配蓝、断言封面配纸）：把观感选择挂回内容判断，
  就重新引入了「自动推导选不出论据」的同族问题——样式选择不需要智能，
  需要的是不可预测性和可复现性，哈希刚好。
- **样式进 spec 由写作层每天挑**：写作层应该把额度花在论据上；样式交给哈希，
  写作层想干预时仍有 `--style` 逃生门。

## Consequences

- 每天的封面观感从 1 种变为最多 8 种轮换，同一天内幂等。
- 旧常量 `INK`/`BLUE`/… 保留（`ink` 样式与历史产物逐像素一致），旧 spec 不写
  `style` 字段自动进入每日轮换——这是一个**行为变化**：同一天重跑旧 spec，
  封面从「永远是 ink」变为「当天哈希选中的那种」。可接受：样式不是论据，
  不影响 ADR-0044 的任何自检结果。
- 新机器缺某个样式字体时静默回落全局 CJK 字体（观感退化，不是错误）——
  自检仍按实际绘制把关可读性。
- 测试：`tests/test_make_cover_style.py`（目录完整性、墨底可分、确定性、
  相邻日错开、未知名报错、钉死生效），3.9/3.12 双跑通过。
