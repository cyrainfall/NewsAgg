# DeepSeek搜索5元一千次，做Agent的成本要重算

DeepSeek 把搜索接口的单价定在了**每 1000 次成功请求 5 元**。折成单次是半分钱。

同一件事，Tavily 的基础搜索是 1 信用一次、按量付费 0.008 美元一次，折人民币约 5 分 7。**差 11 倍。**

但这不是重点。重点是这次降价的**计价单位换了**——过去一年所有人都在比「每百万 tokens 多少钱」，这次比的是「每次调用多少钱」。单位一换，被重新定价的就不是模型，是夹在模型和你的应用中间的那一层。

## 先把这个「半分钱」算成你能对号入座的口径

5 元一千次，听起来像营销数字。换个算法：一个 Agent 每处理一次用户请求要查 5 次网页，一天 100 个请求就是 500 次搜索。

- 走 Tavily：500 × 0.008 = 4 美元，约 28 元
- 走 DeepSeek：500 × 0.005 = 2.5 元

一天差 25 块，一个月差 750 块左右。对一个还在自己掏服务器钱的独立开发者，这个差额正好是一台小机器的月租。

**边界要说清楚**：这是换算，不是实测账单。5 元只算「成功请求」，失败的不计费；Tavily 那边每月还有 1000 次免费额度，所以这个对比只对**超过免费额度的调用量**成立。如果你的 Agent 一个月只查几百次，两边的差别可以忽略，别为省这几十块钱去改架构。

## 模型价格一分没降，降的是「这笔钱该谁收」

这里有个容易被标题盖掉的细节：DeepSeek 这次**模型本身没降价**——峰时输入 0.3 元、输出 1.2 元每百万 tokens，谷时减半，和之前一样。API 名字还是 `deepseek-flash`，10 月 17 日 18:07 三端同步切过去，没有发布会，没有预热。

它换掉的是模型，加进来的是**新的计费项**。

而公告里还有一句更值得注意：Harness、Claude Code、Codex 里那些走服务端的 Search / Fetch 调用，此前一直**没计费**，从 2026 年 11 月 1 日零点起开始按次收。

所以对某一部分人来说，这次不是降价，是**涨价**。同一份公告，对不同位置的人意味着相反的事——这正是「计价单位」比「单价」重要的地方。

## 挨打的不是做模型的，是做中间件的

我原来对价格战的判断写得很清楚：价格战是同质化的信号，它压缩中小模型厂商、繁荣应用层，所以对做应用的人是好事、对做模型的人是坏事。

这一次的事实要把这个判断往前推一格。

被压的不是「做模型的」，是**做中间件的**。为 Agent 提供「怎么找到资料」这件事，过去两年是一门正经生意：搜索 API、网页抓取、内容清洗、代理池，一层层都有人收钱。现在模型厂商把它做成了默认项，价钱压到别人的十分之一。

这件事以前发生过一次，只是当时没那么显眼：检索增强刚流行时，主流做法是自己搭向量库、自己切分、自己清洗，一套流程要养一个工程师。后来搜索能力直接进了 API，**那段工程就从「核心竞争力」变成了「一行参数」**。今天发生的是同一件事的第二遍，只不过这次被收走的是「按次计费的搜索服务」这个位置。

具体是什么感觉？一个做代码助手的独立开发者，为了省 API 费自己写抓取：三百行代码、代理池、反爬对抗、HTML 清洗、每天醒来先看哪个源又挂了。他把这部分交给模型厂商之后，省下的其实不是那几百块，是**一个永远修不完的模块**。这类「省下来的不是钱、是维护面积」的变化，通常比降价本身更能改变一个人的技术选型。

## 便宜是真的，但「超越旗舰」是挑项目说的

需要把能力这一半也讲清楚，否则容易变成一句「反正都是营销」。

进步是真的。有掘金作者拿同一个 prompt 实测：新模型生成 16,735 字节、耗时 71.7 秒、消耗 1.22 credit；上一代 V4-Pro 是 9,906 字节、118.3 秒、6.29 credit。**产出更长、速度快四成、成本约五分之一。**

但官方模型卡全是自报，而且是拿自家挑的 harness 跑的——Terminal-Bench 4.0 用 Claude Code 的框架、DeepSWE 用 mini-swe-v2，没有第三方复核。在 Terminal-Bench 4.0、ProgramBench、HLE 这几项上，它仍明显落后 Claude Opus 5。所以「超越旗舰」这个说法，取决于挑哪张表。

这恰好反过来印证了那条老判断：**当一场发布把重心放在定价和计费方式上，而不是在能力上拉开差距，说明它自己也知道差距在哪。**

还有个实操层面的坑值得提：有实测指出它思考 token 吃得很多，一次任务里思考部分占了 15,349 / 21,333。输出预算给小了会被硬截断——**看似省钱，实际是把任务做废了重跑。**按次计费的时代，最贵的不是单价，是重试。

## 我的结论，和什么情况下我会改口

判断一场 AI 发布，别只盯着单价涨了还是跌了，要看它**把计价单位从什么换成了什么**。从 token 换到「次」，被重估的是一整层中间件；从「按席位」换到「按调用」，被重估的是整套采购逻辑。单价只是这一层变化露在外面的部分。

对做 Agent 的人，这次是实打实的成本下降，但代价是**依赖收窄**：你的搜索能力、抓取质量、可用性，从此和一个模型厂商的排期绑在一起。省下的维护成本是真的，被单点绑定的风险也是真的。我的建议是先把「搜索」这层抽成一个薄接口再切过去——不是为了随时换回来，是为了让自己知道换回来要花多少。

只有一条边界需要声明：**如果 DeepSeek 的单位推理成本并没有同步下降，那这 5 元就是补贴价。**补贴结束，被压走的中间件会回来，判断也会跟着改。验证办法很简单——看 11 月 1 日计费真正开始之后，有没有第二次调价。有，说明这盘生意还撑得住；半年内不动，说明它已经把成本压到那个位置了。
